# Security policy

The current `main` branch and the deployed 0.1.x application are supported with security fixes.

Report a suspected vulnerability through GitHub's private vulnerability reporting flow on the repository **Security** tab. Do not open a public issue for an unpatched vulnerability.

Include the affected component, reproduction steps, impact, and a minimal synthetic example. Never attach real database credentials, private schemas, row data, or personal information. Reports are assessed by impact and exploitability; confirmed Medium, High, and Critical issues block a release until remediated.
